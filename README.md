# 力の種類あて（chikara-shurui）

身のまわりの場面（りんごが落ちる・のばしたばねが引きもどす・すべらせた本が止まる・磁石がクリップを引きよせる・こすった下じきに髪がつく など）を見て、はたらいた力（重力・弾性の力・摩擦の力・磁力・電気の力）を当てる1日5問の学習ゲーム。正解したら「この力のとくちょうは？」も選ぶ。中学1年理科「力の働き」。

遊ぶ: <https://satou-aaaaa.github.io/chikara-shurui/>

- 中身は千葉県教育委員会「やる気アップ 理科」の力の働きのプリント（解答）、大阪府教育委員会の確認プリント（解答）、茨城県教育研修センターの学習指導案で確かめたことだけです。
- 力の大きさの計算は扱いません。このゲームは教科書の代わりではありません。くわしくは教科書で確かめてください。
